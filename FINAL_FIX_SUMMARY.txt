                          ما تحتاج تفعله الآن
================================================================================

الخطوة 1: احصل على Supabase Credentials
─────────────────────────────────────────────
1. اذهب إلى: https://app.supabase.com
2. اختر مشروعك
3. اذهب إلى: Settings → API
4. انسخ:
   - Project URL (مثال: https://abcdefgh.supabase.co)
   - Anon public key (المفتاح الطويل)

الخطوة 2: حدّث .env.local
────────────────────────────
افتح: /vercel/share/v0-project/.env.local

أضف القيم الحقيقية:
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_ANON_KEY_HERE

الخطوة 3: فعّل Email Authentication
─────────────────────────────────────
في Supabase Dashboard:
1. Authentication → Providers
2. تأكد من تفعيل Email
3. Email Confirmations: اختر preferred setting

الخطوة 4: أعد تشغيل المشروع
─────────────────────────────
npm run dev
# أو
pnpm dev
